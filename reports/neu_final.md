# NEU-CLS 工业缺陷分类正式实验（阶段四）

本报告只记录已运行的 NEU-CLS 工业实验；Fashion-MNIST 课程实验独立记录在 `reports/fashion_final.md`。逐次测试指标、混淆矩阵、原始预测及冻结协议分别见 `results/raw/neu_final/` 与 `results/raw/neu_formal_protocol.json`。

## 数据和实验协议

- 数据来自东北大学官方 NEU-CLS 下载入口。六类各 300 张、原始尺寸 200×200 灰度图；固定划分每类训练 180、验证 60、测试 60。主实验只使用训练部分中的 90 张/类，共 540 张；其余训练图像未参与主实验。
- 图像转为 128×128 灰度、强度归一化到 [0,1]。NEU 六分类 CNN 与 NEU 条件卷积 VAE 均从头训练，与 Fashion 模型权重完全独立。
- A：100% 真实训练图像；B：50% 真实 + 50% 轻微几何增强（±5°、0.5 中灰填充、水平翻转概率 0.5）；C：50% 真实 + 50% NEU CVAE 生成图像。
- 三组均用同一 NEU CNN、Adam、学习率 0.001、批大小 32、40 轮、每轮 17 次更新；分类种子 0、1、2。用验证准确率选最佳轮次，全部九次训练后才访问固定测试集。
- CVAE 只使用 540 张小样本训练图，40 轮、潜在维 64、β=1；类别同时条件化编码器与解码器。重建损失按每图像像素求和后按批平均；KL 按潜在维求和后按批平均。每个生成池 90 张/类并保存标签、种子和权重 SHA-256。
- 下表标准差是三个种子的样本标准差（ddof=1）。

## 独立测试结果

| 模式 | Accuracy | Macro-F1 |
|---|---:|---:|
| A 真实数据 | 0.9731 ± 0.0085 | 0.9732 ± 0.0084 |
| B 常规增强 | 0.9769 ± 0.0098 | 0.9770 ± 0.0096 |
| C CVAE 增强 | 0.9343 ± 0.0098 | 0.9343 ± 0.0095 |

B 相比 A 的平均 Accuracy 仅高约 0.0038；三个种子中并非每次都更高。C 比 A 低约 0.0388，额外的生成成本未带来总体收益。数据集总量较小，不将这组结果外推为所有工业缺陷任务的结论。

## 生成质量与错误分析

`results/figures/neu_cvae_diagnostic.png` 并列展示六类真实训练图、指定类别生成图和训练集像素最近邻。生成图常只保留亮暗区域，龟裂细线、麻点颗粒和划痕方向等高频纹理明显模糊。六类代表图中 Cr、Pa、PS、Sc 的像素最近邻均落在 In 类；最近邻仅作图像外观线索，不是语义判定。

按“seed 0 中 A 正确而 C 错误的最小测试索引”选取三个案例，见 `results/figures/neu_final_failures.png` 和 `results/raw/neu_final_failures.json`：

1. `In_248.bmp`：真实夹杂，C 预测为麻点。
2. `Pa_147.bmp`：真实斑块，C 预测为麻点。
3. `PS_90.bmp`：真实麻点，C 预测为夹杂。

夹杂、斑块与麻点的局部深色区域在生成图中更难区分，可能使 C 的决策边界变差；本实验未证明某一张生成图直接造成某个测试错误。应结合逐类召回和全部混淆矩阵看待案例。

## 计算成本与限制

RTX 4060 Laptop GPU 上，模型循环内的 CNN 40 轮训练平均耗时 A 13.81 秒、B 15.10 秒、C 14.00 秒；CVAE 40 轮训练 9.74 秒。每个 540 张生成池耗时 0.048–0.273 秒，受预热状态影响。单张推理与单张生成耗时、GPU 峰值张量分配均保存在 `results/summary/neu_costs.json`。计时不含 Python 启动与图像加载。

这套轻量 CVAE 的生成图偏模糊，是 C 组表现下降的合理候选解释，不能据此断言所有生成式增强都无效。随机图像级划分可能保留同一采集条件下的相似纹理；训练/验证/测试路径无交叉，跨划分的原始文件 SHA-256 也无完全重复。官方页面未明确给出完整再分发许可，原始图像不随公开项目打包。
